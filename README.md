# MJK Abogados - Landing Page

## Descripción

Esta es una landing page para el despacho legal **MJK Abogados**. El sitio presenta la firma con una navegación clara, secciones de información, portafolio de servicios, clientes destacados, equipo, preguntas frecuentes y un formulario de contacto que envía el mensaje mediante WhatsApp.

El diseño busca transmitir profesionalismo, confianza y accesibilidad, con una paleta elegante en tonos oscuros y dorados.

## Secciones principales

1. **Inicio**
   - Hero banner con título, descripción y botones de acción.
   - Enlace directo a la sección de contacto y acceso a WhatsApp.

2. **Sobre Nosotros**
   - Misión y visión del despacho.
   - Valores profesionales y jurídicos.
   - Estadísticas clave.

3. **Servicios**
   - Portafolio de servicios completos para: persona natural, laboral, civil, penal, administrativo, servicios públicos, comerciantes, empresas, inmobiliarias, constructoras y propiedades horizontales.
   - Cada categoría incluye los servicios específicos que ofrece el despacho.

4. **Clientes Destacados**
   - Sección con clientes importantes.
   - Cada cliente posee una tarjeta con foto representativa y descripción.

5. **Equipo**
   - Perfil del equipo principal con fotos reales genéricas y descripciones de experiencia.

6. **Preguntas Frecuentes**
   - Acordeón interactivo para responder inquietudes comunes.

7. **Contacto**
   - Formulario de contacto con nombre, correo, teléfono y mensaje.
   - El envío abre WhatsApp con un mensaje prellenado.
   - Información adicional de contacto con WhatsApp, correo, Instagram, TikTok y cobertura.

## Características principales

- Navegación responsive con menú móvil.
- Scroll suave y animaciones de aparición de contenido.
- Diseño adaptable para dispositivos móviles.
- Sección `Clientes Destacados` con imágenes reales representativas.
- Formulario de contacto que no requiere backend.
- Sección adicional solicitada: `Clientes Destacados` en el menú de navegación.

## Estructura de archivos

- `index.html` - Página principal con toda la estructura del sitio.
- `css/styles.css` - Estilos, layout, tipografía y responsive.
- `js/app.js` - Interactividad de menú móvil, acordeón FAQ, formulario y animaciones.
- `img/` - Carpeta para recursos de imagen como el logo.
- `README.md` - Documentación del proyecto.

## Tecnologías usadas

- HTML5
- CSS3
- JavaScript (Vanilla)
- Font Awesome para iconos
- Google Fonts (`Playfair Display` y `Inter`)

## Instrucciones de uso

1. Abrir `index.html` en un navegador.
2. Navegar por las secciones usando el menú superior.
3. Completar el formulario de contacto y enviar.
4. El formulario redirige a WhatsApp con un mensaje prellenado.

## Personalización

- Cambiar textos y servicios directamente en `index.html`.
- Ajustar colores y espaciado en `css/styles.css`.
- Modificar la lógica del formulario o la URL de WhatsApp en `js/app.js`.

## Notas importantes

- La sección de contacto está configurada para enviar el mensaje a `+57 323 340 0447`.
- Las imágenes de clientes y equipo usan fotografías genéricas de terceros.
- El diseño está optimizado para pantallas anchas y móviles.
